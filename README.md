# Campus-mate 校园搭子小程序
> 软件工程小组作业 | 校园搭子匹配平台

## ✨项目简介
本小程序面向在校大学生，提供搭子发布、兴趣匹配、活动约伴功能，支持学习搭子、运动搭子、美食搭子等多种场景。
