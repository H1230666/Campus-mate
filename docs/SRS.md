# 需求规格说明书（SRS）
## 1 引言
### 1.1 项目背景
校园搭子小程序面向在校大学生，解决学生寻找同行伙伴困难的问题，支持发布搭子需求、兴趣匹配、线上沟通，覆盖学习、运动、美食、出游等校园场景。
### 1.2 项目目标
开发一款轻量化微信小程序，实现搭子信息发布、兴趣标签筛选、用户匹配、消息留言功能，操作简单适配学生群体。
### 1.3 文档目的
本文档记录项目全部功能需求、非功能需求，作为小组开发、测试、汇报的依据。
### 1.4 范围
包含小程序前端页面、后端接口、数据存储；不包含付费、实时视频通话功能。

## 2 总体描述
### 2.1 用户特征
用户：在校大学生，有寻找搭子需求，熟悉微信基础操作。
### 2.2 运行环境
微信小程序客户端；后端部署在云服务器；数据库MySQL。
### 2.3 约束条件
1. 开发周期：第八周完成需求梳理、原型设计；
2. 遵守微信小程序开发规范；
3. 用户信息做基础隐私保护。

## 3 具体需求
### 3.1 功能需求
1. 用户模块：微信授权登录、个人主页、修改兴趣标签、头像昵称编辑
2. 搭子发布模块：发布搭子帖子，填写时间、地点、类型、人数、备注
3. 搭子浏览&匹配模块：按标签筛选帖子、推荐兴趣相近搭子
4. 留言模块：帖子下方留言互动
5. 收藏模块：收藏感兴趣的搭子帖子

### 3.2 非功能需求
1. 性能：页面加载时间≤2s
2. 易用性：界面简洁，新手30秒内学会发帖子
3. 安全性：不泄露用户手机号等隐私信息
4. 可维护性：代码模块化，注释清晰

## 4 界面原型说明
原型使用绘图工具完成，包含首页、发布页、个人中心、详情页，原型截图后续补充到此文件夹。
