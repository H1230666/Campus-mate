### 技术要点

1. **用户建模**：`user` 表 10 个字段（username 唯一索引、password_hash、openid 可空、phone、avatar、interest_tag、is_active、create_time、update_time），
   **密码只存 PBKDF2 哈希，任何位置不落明文**。
2. **入参校验**：Pydantic v2 四个模型（UserCreate / UserUpdate / AdminUserUpdate / UserResponse），
   `field_validator` 实现用户名正则、手机号 11 位、密码首尾空格校验；
   **管理态字段 `is_active` 从自助更新模型移出**，消除越权解封风险。
3. **JWT 鉴权**：python-jose HS256；密钥仅从 `AUTH_SECRET` 读取，**非 dev 环境缺失或长度 <32 位直接终止启动**；
   `get_current_user_openid` 对「未携带 / 格式非 Bearer / 伪造 / 过期」四类情况统一返回 401。
4. **前端**：接口地址统一走 `app.globalData.apiBaseUrl`；401 自动回登录页；头像缺失时用占位视图而非引用不存在的图片。
